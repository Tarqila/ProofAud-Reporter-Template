Proof Audit3.1 · VUL-001
VUL-001 · src/StakingVault.sol · L212–228

{{Share-price rounding allows donation-based share inflation}}

Critical Resolved
Description
{{Explain the root cause. E.g. The vault computes shares as assets * totalSupply / totalAssets. Because division rounds down, an attacker can donate a small amount of the underlying asset to the vault, inflating totalAssets and causing the next depositor to receive zero shares while their assets are credited to existing shareholders.}}
Proof of Concept
1  // attacker donates 1 wei directly
2  asset.transfer(address(vault), 1);
3  // victim deposit rounds down to 0 shares
4  uint256 shares = vault.deposit(1e18, victim); // returns 0
Recommendation
{{Mitigation. E.g. Mint an initial dead-amount of shares on deployment, or use the “virtual shares / assets” pattern (ERC-4626 inflation-attack mitigation), so that share price manipulation is no longer profitable.}}
Resolution
{{Fixed in commit f00ba12 by adopting OpenZeppelin’s ERC-4626 virtual-offset implementation. Verified during retest on {{Aug 19, 2025}}.}}
